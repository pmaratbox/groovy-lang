# 0048 — Maps: Iterate & Transform

Build a map from letters to numbers (`a`->1, `b`->2, `c`->3), sum all its values, and print `sum: 6`. A map literal uses `[key: value]`, and Groovy adds `.values()` plus a collection `sum()` that folds them. Iterating with `.each { k, v -> }` or `.collect` covers transformation.

## Run

    groovy main.groovy
