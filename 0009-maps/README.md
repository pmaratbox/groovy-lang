# 0009 — Maps

Build a map `[one: 1, two: 2, three: 3]`, look up `"two"`, and print its value
and the map's size. The `[key: value]` literal is a `LinkedHashMap` with string
keys. Values are read with `map.two`, `map['two']`, or `map.get('two')`;
`.size()` counts entries.

## Run

    groovy main.groovy
