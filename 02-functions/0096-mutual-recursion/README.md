# 0096 — Mutual Recursion

Using two mutually recursive functions `isEven` and `isOdd` (each calling the other), report whether `4` and `3` are even, printing `even` and `odd`. Script-level methods are all visible to each other, so `isEven` and `isOdd` can call back and forth regardless of order.

## Run

    groovy main.groovy
