# 0053 — Binary Search

Binary-search the sorted array `1, 3, 5, 7, 9` for `7` and print the index where it is found: `found 7 at index 3`. `(lo + hi).intdiv(2)` does integer division (plain `/` would yield a `BigDecimal`). Groovy inherits Java's `Arrays.binarySearch` for the library version.

## Run

    groovy main.groovy
