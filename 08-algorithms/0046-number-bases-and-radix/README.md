# 0046 — Number Bases & Radix

Print the integer `255` in hexadecimal, octal, and binary, producing `hex: ff`, `oct: 377`, and `bin: 11111111`. `Integer` has dedicated converters — `toHexString`, `toOctalString`, and `toBinaryString` — that render an `int` in each base. They wrap the JVM's bit-level formatting.

## Run

    groovy main.groovy
