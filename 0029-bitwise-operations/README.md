# 0029 — Bitwise Operations

Compute bitwise AND, OR, and XOR on `6` and `3`, plus a left shift of `6` by one bit, printing `and: 2`, `or: 7`, `xor: 5`, and `shift: 12`. Groovy's bitwise operators `&`, `|`, `^`, and `<<` map to the JVM integer operations (and to methods like `and`/`or` on `BigInteger`). `6 << 1` shifts left one bit, doubling to 12.

## Run

    groovy main.groovy
