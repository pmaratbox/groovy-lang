# 0003 — Arithmetic & operators

Compute and print the five elementary arithmetic operations on two integers
(`a = 17`, `b = 5`). Groovy's `/` operator on integer operands returns a
`BigDecimal`, not a truncated int — `17 / 5 → 3.4`. Use `a.intdiv(b)` for
integer quotient.

## Run

    groovy main.groovy
