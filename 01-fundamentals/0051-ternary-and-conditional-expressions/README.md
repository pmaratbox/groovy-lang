# 0051 — Ternary & Conditional Expressions

For each of `4` and `7`, choose `even` or `odd` with a single conditional expression and print `4: even` and `7: odd`. Groovy has the `?:` ternary, plus the *Elvis* shorthand `a ?: b` (which yields `a` when truthy, else `b`). `if` is a statement, so the ternary is the inline form.

## Run

    groovy main.groovy
