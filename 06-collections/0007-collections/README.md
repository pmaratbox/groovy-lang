# 0007 — Collections

Build a list of the integers `1, 2, 3, 4, 5`, then print its count and its
first and last elements. The `[...]` literal builds a `java.util.ArrayList`,
and `.size()` is a method. Like Python, Groovy supports negative indices, so
`nums[-1]` is the last element.

## Run

    groovy main.groovy
