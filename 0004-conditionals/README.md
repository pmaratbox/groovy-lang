# 0004 — Conditionals

Compare `n` against 10 and print whether it's less, equal, or greater.
Groovy's `==` is null-safe and calls `.equals()` on objects (unlike Java's
reference comparison); for primitive ints it behaves as expected. Edit `n`
to `10` or `15` to exercise the other branches.

## Run

    groovy main.groovy
