# 0034 — Default & Named Arguments

Give a `greet` function a default greeting, then call it once without the greeting and once overriding it, printing `Hello, Ada` and `Hi, Ada`. Groovy supports default parameter values directly (`greeting = "Hello"`). It also offers named arguments by accepting a leading `Map` parameter, calling `greet(name: "Ada", greeting: "Hi")`.

## Run

    groovy main.groovy
