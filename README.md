# groovy-lang

Incremental lessons learning Groovy.

## Prerequisites

- Groovy (pulls in a JDK as a dependency on most installs)

### Install

- macOS (Homebrew): `brew install groovy`
- Linux / cross-platform (recommended): install [SDKMAN](https://sdkman.io/install), then `sdk install groovy`
- Debian / Ubuntu (system package): `sudo apt install groovy`

### Verify

    groovy --version
