# 0050 — Stacks

Push `1`, `2`, and `3` onto a stack, then pop them all off and print them in last-in-first-out order: `3 2 1`. A Groovy `List` is the stack — `add` appends and `removeLast()` pops from the end, yielding LIFO. (`push`/`pop` also exist but historically operate at the front.)

## Run

    groovy main.groovy
