# 0052 — Queues

Enqueue `1`, `2`, and `3` into a queue, then dequeue them all and print them in first-in-first-out order: `1 2 3`. `java.util.LinkedList` implements `Queue`: `add` enqueues at the tail and `removeFirst()` dequeues from the head. `ArrayDeque` is the faster general-purpose choice.

## Run

    groovy main.groovy
