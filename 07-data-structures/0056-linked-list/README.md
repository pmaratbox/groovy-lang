# 0056 — Linked List

Build a singly-linked list holding `1`, `2`, and `3`, then traverse it from head to tail and print `1 -> 2 -> 3`. A plain class holds `value` and a `next` reference (null at the tail); the optional constructor argument lets the chain be built inline, and traversal follows `next` until null.

## Run

    groovy main.groovy
