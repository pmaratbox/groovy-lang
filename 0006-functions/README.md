# 0006 — Functions

Define `add(a, b)` returning their sum, call it with `3` and `4`, and print
the result. The return type is declared (`int add(...)`); using `def add(a, b)`
instead would make it dynamically typed. The last expression of a method is
**implicitly returned**, so the explicit `return` keyword is optional —
shown here omitted.

## Run

    groovy main.groovy
